## Project Description

Student Budget Tracker API is a REST API project that helps students manage their monthly budget. Students can add income, track expenses, organize spending by categories, and check how much money they have left.

This project is useful because students often need to manage rent, groceries, transportation, tuition, phone bills, and part-time job income. The app will help students understand their spending and make better money decisions.

## Frontend Idea

The frontend will be a simple website where students can manage their personal budget.

Frontend pages:

- Home Page
- Add Income Page
- Add Expense Page
- Expense List Page
- Budget Summary Page
- Category Report Page

Users will be able to:

- Add monthly income
- Add expenses
- View total spending
- View remaining balance
- Filter expenses by category
- See monthly budget summary

## Data Managed by the API

The API will manage:

- Students
- Income
- Expenses
- Categories
- Monthly Budget
